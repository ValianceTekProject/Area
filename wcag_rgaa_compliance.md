# WCAG and RGAA Compliance Analysis

## Reference frameworks

* WCAG 2.1 – Web Content Accessibility Guidelines
* RGAA – General Accessibility Improvement Framework

## Core accessibility principles

The developed interfaces were evaluated according to the four fundamental WCAG principles:

* Perceivable
* Operable
* Understandable
* Robust

## Considered compliance criteria

### Structure and semantics

* Use of semantic HTML elements
* Consistent heading hierarchy
* Logical content organization

### Navigation and interaction

* Full keyboard navigation support
* Coherent tab order
* Clearly identifiable interactive elements

### Readability

* Sufficient contrast between text and background
* Appropriate font sizes
* Clear and explicit user messages

### Compatibility

* Compatibility with assistive technologies
* Avoidance of blocking behaviors for screen readers

## Identified limitations

Some advanced features were not tested with real users with disabilities. These limitations have been identified as improvement areas for future project iterations.

## Conclusion

The project integrates the fundamental principles of WCAG and RGAA from the early design stages. This approach helps reduce late-stage corrections and ensures a more inclusive application.
