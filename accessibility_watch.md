# Accessibility and Disability Inclusion Watch

## Purpose of the watch

The purpose of this accessibility watch is to identify standards, regulations, and best practices related to digital accessibility in order to design an application usable by the widest possible audience, including people with disabilities.

This approach also aims to anticipate legal and technical constraints in order to reduce accessibility-related technical debt.

## Scope

* Web applications
* Mobile applications
* User interfaces
* APIs and error handling
* Development tools and frameworks

## Monitored sources

* W3C – Web Accessibility Initiative (WAI)
* WCAG 2.1 / 2.2
* RGAA (French General Accessibility Improvement Framework)
* Specialized technical articles on digital accessibility
* Official documentation of selected frameworks and libraries
* Professional community feedback and best practices

## Watch frequency

* Targeted research during design phases
* Regular checks during interface development
* Global review at the end of the project

## Analysis focus areas

* Keyboard navigation
* Screen reader compatibility
* Semantic structure of content
* Readability and color contrast
* Clarity of user feedback and messages

## Use within the project

The results of this accessibility watch were used to guide technological choices, interface structure, and the development practices adopted throughout the project.
